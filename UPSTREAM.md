# Upstream Project Attribution

This university DevSecOps project is based on OWASP NodeGoat.

Original project:
https://github.com/OWASP/NodeGoat

NodeGoat provides an intentionally vulnerable Node.js application for
learning how OWASP security risks affect web applications.

The original application is licensed under the Apache License 2.0.

For the IE3142 Continuous Assessment, the project was containerised,
analysed, tested, remediated and integrated with an automated DevSecOps
security pipeline by the student group.
